# CLAUDE.md — <course name>

Guidance for this course in particular. The machinery that builds it — the
settings file, the cover, the stylesheet, the validator — is described in the
`CLAUDE.md` at the project root and is shared with every other course. Keep
this file to what is true of this course alone; whoever is working on its
Markdown reads this one.

Worth filling in:

- **What it is**: who it is for, who the client is, how long it runs, whether
  it is delivered live or online.
- **The documents and how they interlock**: what each one is, and which
  cross-references between them break when something is renumbered.
- **Where it came from**: the transcripts and repo in `source/` the documents
  were written from, and anything that has to be checked against them.
- **Voice**: spelling, person, how much is assumed of the reader, how prompts
  and keystrokes are marked up.
- **Editing rules that matter**: anything agreed with the client, demonstrated
  live and not to be "improved" without re-testing, or otherwise not an
  editorial judgement call.
