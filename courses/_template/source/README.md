# Source material

Transcripts, the session's GitHub repo (or a link to it), slides, scratch
notes - whatever the documents are written **from**.

The build never looks in here. Nothing in this folder is rendered, zipped or
shipped, so it is safe to drop a whole repo clone or a folder of transcripts
in and leave it.

That matters: `files/` is zipped **by file type**, so a `.docx` transcript or
a `.pdf` of reference material left there would be handed to participants
without a word. Inputs live here; hand-outs live in `files/`.
